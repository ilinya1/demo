# 学生宿舍管理系统 — 功能模块说明

## 一、系统概述

学生宿舍管理系统面向**管理员（宿管）和**学生两类用户，提供宿舍与房间管理、入住退宿管理、卫生检查管理、报修管理、学生信息管理、宿舍信息查询与统计等核心功能，实现宿舍管理的信息化、规范化。

- **技术栈**：前端 Vue 3 + Element Plus（前后端分离），后端 Spring Boot + MyBatis-Plus，数据库 MySQL

- **使用方式**：管理员通过 Web 后台进行日常管理；学生通过网页登录查看个人住宿信息、卫生检查结果并提交报修

***

## 二、角色与权限

| 角色          | 权限范围     | 主要功能                                 |
| ----------- | -------- | ------------------------------------ |
| **管理员（宿管）** | 全部管理功能   | 学生管理、宿舍房间管理、入住退宿、卫生检查、报修处理、统计查询、系统设置 |
| **学生**      | 仅查看 + 提交 | 查看个人入住信息、查看本宿舍卫生检查结果、提交报修、查看报修进度     |

> 系统仅区分两类角色，通过用户表的角色字段（role，取值 ADMIN / STUDENT）进行区分，无需复杂 RBAC 权限体系。

***

## 三、功能模块清单（共 7 个模块）

```
学生宿舍管理系统
├── 1. 登录与角色管理
├── 2. 学生信息管理
├── 3. 宿舍与房间管理
├── 4. 入住退宿管理
├── 5. 卫生检查管理
├── 6. 报修管理
└── 7. 宿舍信息查询与统计
```

***

## 四、模块详细功能

### 模块 1：登录与角色管理

| 功能点  | 说明                      |
| ---- | ----------------------- |
| 用户登录 | 管理员、学生通过账号密码登录系统        |
| 角色区分 | 登录后根据角色（管理员/学生）展示不同功能菜单 |
| 修改密码 | 用户可修改自己的登录密码            |
| 退出登录 | 安全退出系统，清除登录状态           |

***

### 模块 2：学生信息管理

| 功能点    | 说明                                          |
| ------ | ------------------------------------------- |
| 学生信息维护 | 新增、编辑、删除学生信息（学号、姓名、性别、学院、专业、班级、联系方式、紧急联系人等） |
| 学生信息查询 | 按学号、姓名、学院、专业、班级等条件查询学生                      |
| 批量导入   | 通过 Excel 批量导入学生信息                           |
| 批量导出   | 将学生信息导出为 Excel 文件                           |
| 学生状态管理 | 管理学生状态（在校 / 毕业 / 退学 / 休学）                   |
| 住宿关联   | 查看学生当前入住宿舍及历史入住记录                           |

***

### 模块 3：宿舍与房间管理

| 功能点    | 说明                            |
| ------ | ----------------------------- |
| 楼栋管理   | 维护宿舍楼栋信息（楼栋名称、楼层数、房间数、楼栋管理员）  |
| 房间管理   | 维护房间信息（所属楼栋、楼层、房间号、床位容量、房间类型） |
| 房间状态管理 | 房间状态：空闲 / 部分入住 / 已满 / 维修中     |
| 入住人数统计 | 实时统计每个房间当前入住人数、剩余床位           |
| 房间信息查询 | 按楼栋、楼层、房间状态等条件查询房间            |

***

### 模块 4：入住退宿管理

| 功能点    | 说明                     |
| ------ | ---------------------- |
| 入住登记   | 为学生分配宿舍、房间、床位，办理入住     |
| 退宿登记   | 办理学生退宿，释放床位资源          |
| 调宿/换宿  | 学生调整宿舍/床位（可选功能，可并入本模块） |
| 入住校验   | 入住时校验房间床位是否充足、学生是否已入住等 |
| 入住历史记录 | 查询学生历次入住、退宿记录          |
| 住宿状态管理 | 管理学生当前住宿状态（在住 / 已退宿）   |

***

### 模块 5：卫生检查管理

| 功能点    | 说明                             |
| ------ | ------------------------------ |
| 检查记录登记 | 管理员登记卫生检查记录（检查日期、房间、评分、扣分项、评语） |
| 检查结果发布 | 检查结果发布后，学生可查看本宿舍的检查结果          |
| 检查记录查询 | 按楼栋、房间、日期、评分等条件查询检查记录          |
| 卫生评比   | 统计优秀宿舍、不合格宿舍，支持卫生评比            |
| 学生端查看  | 学生登录后可查看自己宿舍的历次卫生检查结果          |

***

### 模块 6：报修管理

| 功能点    | 说明                       |
| ------ | ------------------------ |
| 提交报修   | 学生提交报修单（房间、报修物品、问题描述、图片） |
| 报修处理   | 管理员接单、派单、处理、完成报修         |
| 报修状态跟踪 | 报修状态流转：待处理 → 处理中 → 已完成   |
| 报修记录查询 | 按状态、房间、日期等条件查询报修记录       |
| 学生端查看  | 学生可查看自己提交的报修单及处理进度       |

***

### 模块 7：宿舍信息查询与统计

| 功能点      | 说明                     |
| -------- | ---------------------- |
| 宿舍入住情况查询 | 查询各楼栋、各房间的入住情况、空床位、入住率 |
| 学生住宿信息查询 | 按学号/姓名查询学生当前住宿信息       |
| 卫生检查统计   | 统计各楼栋、各学院卫生检查平均分、合格率   |
| 报修统计     | 统计报修数量、处理完成率、常见报修类型    |
| 综合统计报表   | 入住率、退宿率、空床位数等统计报表      |

***

## 五、学生端功能（网页登录）

学生登录后仅展示个人视角页面：

| 功能       | 说明                |
| -------- | ----------------- |
| 我的入住信息   | 查看自己当前所在宿舍楼、房间、床位 |
| 我的卫生检查记录 | 查看本宿舍历次卫生检查评分与评语  |
| 提交报修     | 提交宿舍报修申请          |
| 报修进度查询   | 查看自己提交的报修单处理进度    |

***

## 六、数据库核心表规划（初步）

| 表名             | 说明                   |
| -------------- | -------------------- |
| sys\_user      | 用户表（账号、密码、角色、关联学生ID） |
| student        | 学生信息表                |
| dorm\_building | 楼栋表                  |
| dorm\_room     | 房间表（楼栋、楼层、床位容量、状态）   |
| check\_in      | 入住记录表（学生、房间、入住时间、状态） |
| check\_out     | 退宿记录表                |
| hygiene\_check | 卫生检查记录表              |
| repair\_order  | 报修单表                 |
| notice         | 通知公告表（可选，二期扩展）       |

***

## 七、实施建议

1. **MVP 范围**：先实现核心闭环——登录、学生管理、宿舍房间、入住退宿、卫生检查、查询统计、报修。
2. **开发顺序**：数据库设计 → 后端基础框架（JWT + 统一返回 + 异常处理）→ 登录模块 → 基础数据（学生/宿舍）→ 业务模块（入住退宿/卫生/报修）→ 统计 → 前端页面。
3. **二期扩展**：调宿/换宿、通知公告、晚归考勤、水电费管理、违纪管理等可作为后续扩展模块。
