# 学生宿舍管理系统 — 后端文档

> 依据当前代码编写（2026-09-09）。

后端为 **Spring Boot 单体服务**，基于 MyBatis-Plus + MySQL，轻量 JWT 鉴权，前后端分离，接口统一以 `context-path=/api` 对外。

## 一、技术栈版本

| 依赖 | 版本 | 说明 |
| ---- | ---- | ---- |
| Spring Boot | 4.1.1 | parent，starter=`spring-boot-starter-webmvc` |
| JDK | 17+（本机 21.0.7） | `java.version=17` |
| MyBatis-Plus | 3.5.17 | **`mybatis-plus-spring-boot4-starter`**（Boot4 专用） + `mybatis-plus-jsqlparser`（分页） |
| MySQL | 8.0 | `mysql-connector-j` |
| 鉴权 | jjwt 0.12.6 | JWT 签发/校验；拦截器实现 |
| 密码 | spring-security-crypto | `DelegatingPasswordEncoder`，兼容 `{noop}`/`{bcrypt}` |

## 二、工程结构 `com.gzlg.dorm`

```
com.gzlg.dorm
├── DormApplication.java        启动类
├── controller/            REST 接口（按业务模块）
├── service/               业务接口；service/impl 实现
├── mapper/                MyBatis-Plus BaseMapper
├── entity/                实体（@TableName 映射 13 张表）
├── dto/                   入参（@Valid 校验）
├── vo/                    视图对象
└── common/
    ├── result/            Result<T>{code,msg,data}；PageResult<T>{list,total}
    ├── exception/         BizException + GlobalExceptionHandler（统一转 Result）
    ├── jwt/               JwtInterceptor（鉴权）+ WebMvcConfig（鉴权 + 静态 /uploads）
    ├── config/            MybatisPlusConfig（分页拦截器）、PasswordEncoderConfig
    └── util/              BedNoUtil（床位号归一化）等
```

## 三、启动与配置

- 启动：`mvn spring-boot:run`（生产：`mvn -DskipTests package` → `java -jar target/demo-0.0.1-SNAPSHOT.jar`）。
- `src/main/resources/application.yaml`：端口 `8080`、`context-path=/api`、数据源 `dorm_manager`（root）；`jwt.secret/expire-minutes` 支持 `${JWT_SECRET:...}` 环境变量覆盖；MyBatis-Plus 驼峰映射开启、无逻辑删除。
- 建库：执行 `docs/sql/init.sql`（13 张表 + 种子）。

## 四、鉴权（JWT）

- `JwtInterceptor` 拦截 `/**`，放行 `/auth/login` 与 `/uploads/**`；其余需有效 `Authorization: Bearer <token>`。
- 登录签发 token（secret 见 `application.yaml`/环境变量，有效期默认 720 分钟）。密码用 `DelegatingPasswordEncoder`（演示 `{noop}`，改密后落 `{bcrypt}`）。

## 五、统一返回与异常

- 成功返回 `Result{O=OK,msg,data}`；分页返回 `PageResult{list,total}`。
- 业务失败抛 `BizException`，`GlobalExceptionHandler` 统一转 `Result{code(业务码),msg}`；未知异常记日志。
- 数据库约束：**逻辑外键，无物理外键**，完整性由 Service 层校验。

## 七、关键设计点

- **分页**：`MybatisPlusConfig` 注册 `PaginationInnerInterceptor(DbType.MYSQL)`，否则分页 total 恒为 0。
- **退宿双路径**：`check_in.source` 区分 `apply`（学生申请审核通过）/ `direct`（管理员直接退宿）。
- **学院软关联**：`class.college` / `student.college` 以 `t_college.name` 字符串关联；改名用 `LambdaUpdateWrapper` 级联，删除前引用拦截（`CollegeService`）。
- **床位号**：库存 `N号床`，对外接口经 `BedNoUtil.strip` 归一化为数字（匹配前端契约）。
- **图片存储**：`hygiene_record.photos`、`repair_order.images` 为 `LONGTEXT`，存前端 base64 data URL 的 JSON 数组；后端 `addResourceHandlers` 映射 `file:uploads/`（样例图）。
- **统计实时性**：三张台账与仪表盘均由 Service 基于库实时聚合，不写死。
- **学生删除联动**：删除在住学生时释放床位、重算房间占用、清理入住，避免孤儿数据。

## 八、测试

- 9 个测试类、30 个 `@Test`：Auth / BaseData / College / Accommodation / DailyManagement / Stats / ProfileSettings / MapperSmoke / DormApplication。
- 使用**独立测试库** `dorm_manager_test`（`@ActiveProfiles("test")`，`src/test/resources/application-test.yaml`），与演示库 `dorm_manager` 隔离，`mvn test` 不污染演示数据。
- 测试库初始化：先跑 `docs/sql/init.sql` 建演示库，再按 `docs/sql/refresh-test-db.cmd`（或手动 mysqldump 克隆）准备测试库。
