## 二、技术选型（v1 定稿）

### 2.1 后端

| 事项   | 选型                                          | 说明                                                                                                                           |
| ---- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 框架   | Spring Boot 4.1.1（Java 17+，本机用 JDK21）       | 当前最新稳定版（2026-08-20）；4.1.x OSS 支持至 2027-06                                                                                    |
| 持久层  | MyBatis-Plus 3.5.17                         | ⚠️ 依赖须用 `mybatis-plus-spring-boot4-starter`（Spring Boot 4 专用，勿用 boot/boot3 starter）；实体映射 + Service 封装 + 逻辑外键校验在 Service 事务内做 |
| 数据库  | MySQL 8.0+（utf8mb4）                         | 库名 `dorm_manager`                                                                                                            |
| 包结构  | `com.gzlg.dorm`                             | 从 `com.example.demo` 重构                                                                                                      |
| 鉴权   | JWT + Spring Security（或轻量拦截器）               | mock 阶段先假登录，联调时启用                                                                                                            |
| 统一返回 | `Result<T>` + `PageResult<T>`               | code/message/data                                                                                                            |
| 参数校验 | `spring-boot-starter-validation`            | JSR-303 校验                                                                                                                   |
| 密码   | Spring Security `DelegatingPasswordEncoder` | 支持 `{noop}` 明文（演示）与 `{bcrypt}`                                                                                               |

### 2.2 前端

| 事项   | 选型                          | 说明                           |
| ---- | --------------------------- | ---------------------------- |
| 框架   | Vue 3（`^3.5`）               | 当前稳定 3.5.x（3.6 刚 RC，暂不用于生产）  |
| 构建   | Vite `^8`（可用 `^7`）          | Vite8 基于 Rolldown，Node 24 兼容 |
| 路由   | Vue Router `^4`             | admin/student 双端路由 + 登录守卫    |
| 状态   | Pinia `^3`（4.0 已发，ESM-only） | 用户信息 / token / 全局            |
| HTTP | Axios `^1`                  | 拦截器统一带 token、统一处理 Result/错误  |
| UI   | Element Plus `^2.14`        | 复用原型页面布局与交互（表格/表单/弹窗/上传）     |
| 目录   | `frontend/`                 | 保留 `prototype/` 静态原型作参考      |

### 2.3 通用约定

- 逻辑外键：`_id` 结尾字段不建物理外键，完整性统一由后端 Service 在事务内校验（遵守数据库基线硬约束）。

- 冗余联动：`student.housing_status` 由入住/退宿 Service 维护；`dorm_bed.status` 由入住/退宿/维修维护；`dorm_room.status` 由床位占用情况维护；`dorm_room.capacity` 与 `dorm_bed` 行数一致由 Service 在新建房间时保证。

- 快照：`check_in` 写入 5 个名称快照，退宿不覆盖。

- 枚举字典：全部与 v4 对齐（详见第三章）。

- 退宿申请"待审核"可撤销＝直接删除记录；已通过/已驳回不允许撤销。

- 图片上传：一期存储本地目录（如 `frontend` 可访问的静态目录或后端 `uploads/`），路径以 JSON 数组存 `photos`/`images`；二期切换 OSS。

## 四、统一返回 / 异常 / 分页约定

```
Result<T>   { code: Integer, message: String, data: T }
PageResult<T> { total: Long, pageNum: Integer, pageSize: Integer, records: List<T> }
```

| code | 含义                       |
| ---- | ------------------------ |
| 200  | 成功                       |
| 400  | 参数校验失败/BizException 业务错误 |
| 401  | 未登录 / token 失效           |
| 403  | 无权限（角色不符）                |
| 404  | 资源不存在                    |
| 500  | 服务器内部错误                  |

- 业务错误统一抛 `BizException(code, message)`，由 `GlobalExceptionHandler` 转 `Result`。

- 登录接口与 mock 阶段返回真实结构，其余接口 `data` 结构以接口契约为准。
