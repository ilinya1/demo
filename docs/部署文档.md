# 部署文档 — 学生宿舍管理系统（Docker Compose 全容器）

本项目用 **Docker Compose 一键部署**三个互相连通的服务：

| 服务 | 说明 | 对外端口 |
| ---- | ---- | ---- |
| `frontend` | Nginx 托管前端静态资源，并把 `/api`、`/uploads` 反代给后端 | `APP_PORT`（默认 80） |
| `backend` | Spring Boot jar（context-path `/api`） | 8080 |
| `mysql` | MySQL 8，首次自动执行 `docs/sql/init.sql` 建库 + 种子 | 不对外 |

所有部署产物已随仓库提供：
`docker-compose.yml`、`docker/backend.Dockerfile`、`docker/frontend.Dockerfile`、`frontend/nginx/default.conf`、`frontend/.env.production`、`.env.example`。

---

## 一、前置要求（服务器）

- 已安装 Docker 与 Docker Compose V2（`docker compose version` 可用）
- 至少预留：CPU 2 核、内存 2GB、磁盘 3GB
- Linux 建议；Windows 可用 Docker Desktop（命令相同）

## 二、拿到项目代码并配置

在服务器上：

```bash
# 1. 获取代码（或用已打包上传的源码）
git clone <你的仓库地址> dorm && cd dorm

# 2. 复制环境变量并按需修改（MySQL 密码、JWT 密钥、端口）
cp .env.example .env
#   编辑 .env：把 JWT_SECRET 改为强随机串（可 openssl rand -hex 32 生成）

# 3. 确认建库脚本存在（docker compose 会用它在 MySQL 首次启动时建库+种子）
ls docs/sql/init.sql
```

> `.env` 已被 `.gitignore` 忽略，不会提交仓库；`.env.example` 为模板。

## 三、一键启动

```bash
docker compose build   # 首次构建前后端镜像（稍慢）
docker compose up -d   # 后台启动三容器
```

首次启动 MySQL 会执行 `init.sql`（建库 `dorm_manager`、13 张表与演示数据），并校验后端健康后启动。

## 四、验证

```bash
docker compose ps                        # 三容器 status 应为 running
# 浏览器访问
curl -I http://服务器IP/                 # 前端首页 200
curl -X POST http://服务器IP/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"123456"}'   # 应返回 code:0 + token
```

前端登录：`admin/123456`；学生 `2023010101/123456`。

## 五、日常运维

| 操作 | 命令 |
| ---- | ---- |
| 查看日志 | `docker compose logs -f backend` / `frontend` / `mysql` |
| 停止 | `docker compose down` |
| 停止并清数据卷 | `docker compose down -v`（**会删除数据库数据**） |
| 升级代码 | 重新 `git pull` 后 `docker compose build && docker compose up -d` |
| 重建测试库 | 参考 `docs/sql/refresh-test-db.cmd`（本机/测试环境用） |

## 六、配置项说明（.env）

| 变量 | 默认 | 说明 |
| ---- | ---- | ---- |
| `MYSQL_ROOT_PASSWORD` | `DormRoot123456!` | MySQL root 密码，同时被后端连接使用 |
| `JWT_SECRET` | 占位串 | **必须改为强随机密钥** |
| `JWT_EXPIRE_MINUTES` | `720` | token 有效期（分钟） |
| `APP_PORT` | `80` | 前端对外端口 |

后端其余配置（如数据库连接）由 `docker-compose.yml` 的 `SPRING_DATASOURCE_*` 注入；`src/main/resources/application.yaml` 的 `jwt.secret` 支持 `${JWT_SECRET:...}` 占位。

## 七、安全与生产建议

- 一定把 `.env` 里的 `JWT_SECRET` 换成强随机值，并修改 `MYSQL_ROOT_PASSWORD`。
- 生产建议把后端 `8080` 端口**仅对内部开放**（前端 Nginx 反代转发），前端 Nginx 承载对外访问（可加 HTTPS）。
- 卫生/报修图片为 **base64 存库**（`LONGTEXT`），Nginx 已调大 `client_max_body_size 50m` 以容纳大图 JSON。
- 覆盖系统默认 `admin/123456` 等演示密码（在系统设置/改密中修改）。

## 八、非 Docker 方式（备选）

若服务器不便用 Docker，可手动部署：
1. 后端：`mvn -DskipTests package` 得 `demo-0.0.1-SNAPSHOT.jar`，`java -jar` 运行（用环境变量覆盖数据库连接与 `JWT_SECRET`）。
2. 前端：`cd frontend && npm ci && npm run build` 得 `dist/`，用 Nginx 托管并按 `frontend/nginx/default.conf` 配置 `/api`、`/uploads` 反代。
3. 数据库：在本机 MySQL 执行 `docs/sql/init.sql`。
