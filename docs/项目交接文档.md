## 一、项目概览

- **系统名称**：学生宿舍管理系统

- **定位**：高校宿舍的入住退宿、卫生检查、报修管理等信息化管理平台

- **当前形态**：

  - 前端主实现：**Vue 3 单页应用**（`frontend/`），默认对接真实后端；`frontend/src/mock` 为可选内置 mock（可在 `.env.development` 切换）；`prototype/` 为早期静态 HTML 原型，保留作设计参考与字段基线

  - 后端：**Spring Boot 4.1.1**（`src/`），已业务化：JWT 鉴权、仪表盘+三张台账统计、基础数据、住宿、日常、个人中心、系统设置等接口全部落地，接入 MySQL 持久化

  - 数据库：**已建库运行** `dorm_manager`（MySQL8），**13 张表**；唯一建库脚本 `docs/sql/init.sql`（与 `docs/数据库设计说明.md` 同步）

- **技术栈**：

  - 后端：Spring Boot 4.1.1 / JAVA（`pom` 目标 JDK17，本机运行 JDK21）/ MyBatis-Plus 3.5.17（`mybatis-plus-spring-boot4-starter` + `mybatis-plus-jsqlparser`）/ MySQL 8（`mysql-connector-j`）/ JWT `jjwt 0.12.6` / `spring-security-crypto`（密码编码，非完整 Security）

  - 前端：Vue ^3.5 / Vite ^6 / Element Plus ^2.14 / Pinia ^3 / Vue Router ^4.5 / Axios ^1.7 / ECharts ^6（统计报表）

## 三、数据库设计（13 张表）

唯一建库脚本 `docs/sql/init.sql`；字段级字典、ER、枚举约定详见《数据库设计说明.md》。**改表须同步 init.sql / 数据库设计说明 / 实体。**

| # | 表名 | 说明 | 关键字段/约定 |
| :-: | ---- | ---- | ---- |
| 1 | `student` | 学生 | PK=student_id(学号)；class_id→class；college/major 为字符串；academic_status + housing_status(冗余)；contact_phone/emergency_contact/emergency_phone |
| 2 | `class` | 班级主数据 | class_name 唯一；college/major/grade/head_teacher |
| 3 | `sys_user` | 登录账号 | username 唯一、student_id 唯一；role=ADMIN/STUDENT；密码 BCrypt（演示 `{noop}` 明文） |
| 4 | `dorm_building` | 楼栋 | building_name 唯一；floor_count/room_count/manager |
| 5 | `dorm_room` | 房间 | building_id→楼栋；唯一(building_id, room_no)；floor/capacity/room_type(四人间/六人间)/status |
| 6 | `dorm_bed` | 床位 | room_id→房间；唯一(room_id, bed_no)；status=空闲/占用/维修；bed_no 对外统一返回数字（BedNoUtil.strip） |
| 7 | `check_in` | 住宿记录（核心） | 关联 student/building/room/bed（均 NOT NULL）+ 5 快照字段；check_in_time/check_out_time/source(apply/direct)/status |
| 8 | `checkout_apply` | 退宿申请 | apply_no 唯一；reason/plan_date/description/status/reject_reason/create_time/audit_time |
| 9 | `hygiene_record` | 卫生检查 | building_id/room_id(均 NOT NULL)/score/result/deduct_items(JSON)/photos(LONGTEXT base64)/comment |
| 10 | `repair_type` | 报修类型字典 | name 唯一；sort；内置 灯管/水龙头/空调/门锁/床铺/桌椅/其他 |
| 11 | `repair_order` | 报修 | order_no 唯一；student/building/room/type_id→repair_type(均 NOT NULL)；description/contact_phone/images(LONGTEXT base64)/status/handler_name/handler_phone/handle_desc |
| 12 | `sys_parameter` | 系统参数 | param_key 唯一；param_name/param_value；内置 systemName/welcomeMessage/contactPhone/contactEmail |
| 13 | `t_college` | 学院 | name 唯一；sort；class.college / student.college 为其字符串软关联（改名级联、删除拦截由 Service 校验） |

> 约定：逻辑外键（`_id` 关联）不建物理 FOREIGN KEY，完整性由 Service 在事务内校验兜底；`student.housing_status` 由入住/退宿 Service 同步维护。整理枚举：学籍 在校/毕业/退学/休学，住宿 在住/已退宿/未住，房间 空闲/部分入住/已满/维修中，床位 空闲/占用/维修，退宿申请 待审核/已通过/已驳回，报修 待处理/处理中/已完成，卫生 优秀/合格/不合格。

## 四、后端实现要点（接管须知）

- **登录鉴权**：`AuthController` + `AuthService` 校验 `sys_user`（`DelegatingPasswordEncoder` 兼容 `{noop}/{bcrypt}`）→ 签发 JWT；`JwtInterceptor` 校验 token、`UserContext` 持有当前登录用户；改密 + 管理员重置学生密码（`AccountService`）。

- **统计实时聚合**：`Dashboard`（运营工作台）与三张台账统计（入住率/卫生/报修）均由后端**按表实时聚合**，非静态数据。`/dashboard/building-occupancy` 与 `/dashboard/hygiene-trend` 返回**顶层数组**（联调已确认）。

- **分页**：`MybatisPlusConfig` 注册 `PaginationInnerInterceptor`（由 `mybatis-plus-jsqlparser` 提供），分页查询依赖该插件，勿移除。

- **图片存储**：`hygiene_record.photos`、`repair_order.images` 以 **LONGTEXT 存 base64**（非文件路径）；前端组件直接回显。

- **床位号映射**：`BedNoUtil.strip` 保证床位号对外统一返回数字（去掉「号床」等中文）。

- **学院**：`t_college` 已接后端，`CollegeController`/`CollegeService` 实现增删改查、重名拦截、改名级联班级/学生、删除引用拦截。

- **参数校验**：DTO 使用 JSR-303（`spring-boot-starter-validation`）；`GlobalExceptionHandler` 统一处理 `BizException` 与参数错误。

## 五、前端实现要点

- `api/request.js`：统一解包 `Result`、token 注入、401 拦截；`VITE_USE_MOCK=false`（`.env.development` 默认）走真实后端。

- 双端侧边栏品牌名、登录页欢迎语读取系统参数，改后即时反映。

## 六、运行方式

### 后端

```
# 建库：在 MySQL8 执行 docs/sql/init.sql（唯一建库脚本，创建 dorm_manager 与 13 张表及演示数据）
# 启动：
mvnw spring-boot:run
# 访问基址 http://localhost:8080/api（context-path /api）
```

- `application.yaml` 数据源：`localhost:3306/dorm_manager`，user `root` / pwd `123456`；JWT secret/expire-minutes 如需调整在此修改。

### 前端

```
cd frontend
npm install
npm run dev        # http://localhost:3001
```

- `vite.config.js`：dev 端口 3001；`/api` 与 `/uploads`（rewrite → `/api`）代理到 `http://localhost:8080`。

### 测试库

- 测试类标注 `@ActiveProfiles("test")`，走 `application-test.yaml` 的独立测试库 **`dorm_manager_test`**，与演示库 `dorm_manager` 隔离。
- 重建测试库：运行 `docs/sql/refresh-test-db.cmd`（内部基于 init.sql 初始化）。

> 注：原 `start-dev.cmd` 启动脚本已删除，前后端分别以上述命令启动即可。
