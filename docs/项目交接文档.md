## 一、项目概览

- **系统名称**：学生宿舍管理系统

- **定位**：高校宿舍的入住退宿、卫生检查、报修管理等信息化管理平台

- **当前形态**：

  - 前端：纯静态 HTML 原型（`prototype/`）

  - 后端：Spring Boot 4.1.1 骨架（`src/`，尚未业务化）

  - 数据库：**设计定稿**（`docs/sql/init.sql` + `docs/数据库设计说明.md`），未建库运行

- **运行方式**：前端直接用浏览器打开 `prototype/index.html` 即可预览交互，无需编译、无后端依赖；数据库脚本用于后续建库，当前尚无运行中的数据库实例。

- **技术栈**：HTML5 / CSS3 / 原生 JavaScript（`common.js` / `common.css`）；后端 Java 17 + Spring Boot 4.1.1（预计引入 MyBatis-Plus + MySQL）。

## 五、v4 —— 数据库设计落地与终核

> 状态：已完成 ✅（产出：`docs/sql/init.sql` + `docs/数据库设计说明.md`，并经过 4 轮复核）

### v4.1 设计决策（核心，后续后端必须遵守）

| 决策                    | 内容                                                                                                                          |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **逻辑外键**              | 关联字段以 `_id`（或 `student_id`/`order_no` 等业务键）表示，**不建物理 FOREIGN KEY**；完整性由后端 Service 在事务内校验兜底。代价是数据库不兜底，故所有写接口必须走统一 Service 校验 |
| **快照冗余（仅 check\_in）** | 住宿历史为核心审计读路径，入住时写入 `student_name/class_name/building_name/room_no/bed_no` 文本快照，**退宿不覆盖**；卫生/报修房间号稳定，不加快照                    |
| **冗余联动**              | `student.housing_status`（在住/已退宿/未住）冗余在 student 表，由入住/退宿 Service 同步维护，避免每页 join                                              |
| **床位独立建模**            | `dorm_bed` 独立表（room\_id + bed\_no + status），支撑 room-detail 床位分布，二期调宿/维修床可复用                                                 |
| **账号体系**              | `sys_user` 统一承载管理员与学生登录；学生 `username` 与学号同值并关联 `student_id`，密码存 BCrypt（演示样本 `{noop}` 明文）                                    |
| **多图存储**              | `hygiene_record.photos`、`repair_order.images` 以 TEXT 存路径列表(JSON)，一期本地目录、二期 OSS                                              |
| **二期预留策略**            | 不预留死字段；`notice/水电/违纪` 二期再建表；`check_in` 天然支持调宿、`sys_user.role` 可扩 TEACHER                                                    |

### v4.2 数据库全貌（10 张表）

|  #  | 表名               | 说明           | 关键字段/约定                                                                                                                                      |
| :-: | ---------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
|  1  | `class`          | 班级主数据        | class\_name 唯一；college/major/grade/head\_teacher                                                                                             |
|  2  | `student`        | 学生           | PK=student\_id(学号)；class\_id→class；academic\_status + housing\_status(冗余)；contact\_phone                                                     |
|  3  | `sys_user`       | 登录账号         | username 唯一、student\_id 唯一；role=ADMIN/STUDENT                                                                                                |
|  4  | `dorm_building`  | 楼栋           | building\_name 唯一；floor\_count/room\_count/manager                                                                                           |
|  5  | `dorm_room`      | 房间           | building\_id→楼栋；唯一(building\_id, room\_no)；capacity/room\_type/status                                                                        |
|  6  | `dorm_bed`       | 床位           | room\_id→房间；唯一(room\_id, bed\_no)；status=空闲/占用/维修                                                                                            |
|  7  | `check_in`       | **住宿记录（核心）** | 关联 student/building/room/bed（均 NOT NULL）+ 5 快照字段；check\_in\_time/check\_out\_time/source/status                                              |
|  8  | `checkout_apply` | 退宿申请         | apply\_no 唯一；reason/plan\_date/description/status/reject\_reason/create\_time/audit\_time                                                    |
|  9  | `hygiene_record` | 卫生检查         | check\_date/checker/building\_id/room\_id(均 NOT NULL)/score/result/deduct\_items(JSON)/photos(JSON)/comment                                  |
|  10 | `repair_order`   | 报修           | order\_no 唯一；student/building/room(均 NOT NULL)；item/description/contact\_phone/images(JSON)/status/handler\_name/handler\_phone/handle\_desc |

> 字段级完整字典、ER 关系、索引、枚举字典见《数据库设计说明.md》；建表语句与示例数据见 `init.sql`。

### v4.3 多轮复核与修复（A\~F 类）

四轮复核累计修复问题（详见《HTML原型修改记录.md》#7\~#11）：

- **A 类（必须修）**：样例数据矛盾（房间"部分入住"却无人无床）→ 补入住样例复刻原型；密码标注与示例冲突（`{noop}` vs BCrypt）→ 澄清为"演示明文占位、生产 BCrypt"；文档 `student.id`→`student.student_id` 笔误

- **B 类（字段级加固）**：`check_in` 的 building/room/bed\_id 改 `NOT NULL`；`sys_user.student_id` 加唯一约束

- **C 类（严格度统一）**：`hygiene_record`/`repair_order` 的 building/room\_id 改 `NOT NULL`（与 check\_in 一致，原型均必填）；给 `check_in` 补 `(status, check_out_time)` 退宿统计索引

- **E 类（前端枚举对齐）**：`student-list.html` 住宿状态"已退"→"已退宿"，全站残留清零

- **F 类（约定补充）**：退宿申请待审核可"撤销"（直接删除记录，不加枚举）
